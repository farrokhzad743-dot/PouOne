# PouOne — وب‌سایت

مالک و صاحب اثر: **Farrokhzad Parvareh** — © 2026، همه‌ی حقوق محفوظ است (فایل `LICENSE`).

وب‌سایت تک‌صفحه‌ای و استاتیک مجموعه PouOne با محصولات SharePou، RoutePou، PrintPou، ConnectPou، DocPou، PixPou و PlayerPou.

- فقط HTML + CSS + JavaScript، بدون بک‌اند و بدون ابزار Build
- فارسی و راست‌چین، طراحی مینیمال و شیشه‌ای، حالت روشن و تیره (دکمه‌ی آیکونی)
- هر محصول صفحه‌ی اختصاصی دارد (مسیر `#sharepou`، `#routepou`، `#printpou`، `#connectpou`) و دکمه‌ی برگشت مرورگر هم کار می‌کند
- هیچ پوشه‌ای وجود ندارد؛ همه فایل‌ها کنار هم هستند

## فایل‌ها

```
index.html   صفحه اصلی
style.css    استایل‌ها
boot.js      اجرای زودهنگام (تم و کلاس js) برای جلوگیری از پرش نمایش
app.js       منطق صفحه و مسیریابی
config.js    لینک‌های دانلود (اینجا ویرایش کنید)
products.js  متن کامل محصولات
*.webp *.png لوگوها و آیکون‌ها
CNAME  sitemap.xml  robots.txt  manifest.webmanifest  humans.txt  LICENSE  دامنه، سئو و مالکیت
```

## انیمیشن و سئو

- انیمیشن‌ها فقط با transform و opacity ساخته شده‌اند (سبک). در دسکتاپ با موس: پارالکس هیرو، شیب و نور کارت‌ها و دکمه‌های مغناطیسی. در موبایل: ورود کلمه‌به‌کلمه‌ی تیتر، نوار متحرک، آیکون‌های شناور و نوار پیشرفت اسکرول. اگر کاربر «کاهش حرکت» را در سیستم روشن کرده باشد، انیمیشن‌ها خاموش می‌شوند.
- سئو: عنوان، توضیحات، کلمات کلیدی، متاهای اشتراک‌گذاری، متن جایگزین تصاویر و بخش سؤالات متداول در `index.html`. هر محصول هنگام باز شدن عنوان و توضیحات متای خودش را می‌گیرد.

## فونت

فونت‌ها از Google Fonts بارگذاری می‌شوند: Vazirmatn برای فارسی و Sora برای متن انگلیسی (تعریف در `index.html` و `style.css`).

## امنیت دانلود

در `config.js` می‌توانید برای هر فایل `version` و هش `sha256` بنویسید؛ در صفحه‌ی محصول همراه دکمه‌ی «کپی» نمایش داده می‌شود. هش را بعد از ساخت نسخه‌ی نهایی با `certutil -hashfile نام‌فایل SHA256` (ویندوز) یا `sha256sum` (لینوکس/مک) بگیرید.

## حریم خصوصی

صفحه‌ی `#privacy` در `index.html` (بخش `legal`) قابل ویرایش است. بند «برنامه‌ها» را قبل از انتشار برنامه‌ها با واقعیت داده‌های هر برنامه تطبیق دهید.

## لینک دانلود

در `config.js` آدرس دانلود نسخه‌ی اندروید و ویندوز هر محصول را بنویسید. لینک باید با `https://` شروع شود (یا نام فایلی کنار `index.html` باشد)؛ در غیر این صورت دکمه «به‌زودی» می‌ماند و یک هشدار در کنسول مرورگر نوشته می‌شود. مقدار خالی هم یعنی «به‌زودی».

## ارتباط با ما

دکمه‌های تلگرام و ایمیل در `index.html` (بخش `contact`) تعریف شده‌اند.

## انتشار روی ریپوی جدید با دامنه‌ی pouone.ir

1. روی گیت‌هاب یک ریپوی جدید بسازید (مثلاً `PouOne`) و همه‌ی فایل‌های همین پوشه را در ریشه‌ی آن بگذارید:
   ```
   git init -b main
   git add -A && git commit -m "PouOne website"
   git remote add origin https://github.com/farrokhzad743-dot/PouOne.git
   git push -u origin main
   ```
2. Settings ← Pages ← Source: *Deploy from a branch* ← `main` / `/ (root)`. فایل `CNAME` (حاوی `pouone.ir`) از قبل آماده است. بعد از صدور گواهی، گزینه‌ی **Enforce HTTPS** را روشن کنید.
3. در DNS دامنه‌ی `pouone.ir`:
   - چهار رکورد `A` برای ریشه (`@`): `185.199.108.153` ، `185.199.109.153` ، `185.199.110.153` ، `185.199.111.153`
   - یک رکورد `CNAME` برای `www` به `farrokhzad743-dot.github.io`
   با این تنظیم `www.pouone.ir` خودکار به `https://pouone.ir` هدایت می‌شود.
4. بعد از فعال شدن سایت، `https://pouone.ir` را در Google Search Console ثبت کنید و `https://pouone.ir/sitemap.xml` را بفرستید.

نکته: آدرس‌های `canonical`، `og:url`، `og:image`، `sitemap.xml`، `robots.txt` و داده ساختاریافته‌ی JSON-LD همگی روی `https://pouone.ir/` تنظیم شده‌اند. اگر دامنه را تغییر دادید، این فایل‌ها را هم عوض کنید.

## لوگوها و تصاویر

- `pouone-logo.webp`: فقط نوشته‌ی PouOne (در هدر؛ در حالت روشن با فیلتر CSS رنگ می‌گیرد).
- `pouone-mark.webp`: لوگوی P (فعلاً در صفحه استفاده نمی‌شود؛ توپک وسط هیرو حذف شده است).
- آیکون هفت محصول: `sharepou`، `routepou`، `printpou`، `connectpou`، `docpou`، `pixpou`، `playerpou` (هر کدام `نام.webp`). روی کارت‌ها و صفحه‌ی هر محصول نمایش داده می‌شوند.
- رنگ هر محصول در `style.css` (متغیر `--c` برای `[data-p=...]`) از روی خود آیکونش گرفته شده است.

## RoutePou

لینک دانلود ویندوز و اندروید در `config.js` و دکمه‌ی «بازدید از وب‌سایت» (`https://routepou.pouone.ir`) در `products.js` (فیلد `website`) تنظیم شده است. برای هر محصول دیگری هم می‌شود همین فیلد را اضافه کرد.

## کش و نسخه‌ی فایل‌ها

در `index.html` متاهای `Cache-Control`، `Pragma` و `Expires` گذاشته شده‌اند، اما مرورگرهای امروزی آن‌ها را نادیده می‌گیرند و هدرهای واقعی را گیت‌هاب پیجز تعیین می‌کند. راه مطمئن برای دیدن تغییرات بعد از انتشار، عوض کردن عدد `?v=20261109` کنار `style.css`، `app.js`، `boot.js`، `config.js`، `products.js` و `manifest.webmanifest` در `index.html` است (مثلاً هر بار تاریخ روز را بگذارید).

## robots و امنیت

`robots.txt` و متای `robots` فقط به ربات‌های موتور جستجو می‌گویند چه چیزی را ایندکس کنند و جلوی نفوذ را نمی‌گیرند. محافظت واقعی: 2FA روی گیت‌هاب، CSP داخل `index.html`، جلوگیری از باز شدن سایت داخل iframe (`boot.js`) و در صورت امکان Cloudflare جلوی دامنه.

## سئو

عنوان، توضیحات، کلمات کلیدی، داده ساختاریافته (Organization، Person مالک، WebSite، WebPage، چهار SoftwareApplication و FAQPage)، `sitemap.xml` و `manifest.webmanifest` در ریشه قرار دارند. تاریخ `lastmod` در `sitemap.xml` و `dateModified` در داده ساختاریافته را با هر انتشار به‌روز کنید.
